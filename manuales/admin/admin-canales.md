# Manual de Usuario - Canales (Panel Administrador)

Los canales definen categorías de denuncia (ej: "Corrupción", "Acoso laboral").

**Agregar Canal:**
- Solo requiere nombre

**Editar Canal:**
- **Imagen**: Icono representativo
- **Nombre/Descripción**: Identificación del canal
- **Cuestionario**: Formulario que verá el denunciante
- **Destinatarios**: Usuarios que recibirán las denuncias de este canal
- **Recordatorio**: Días para notificar al destinatario si no revisa el reporte (0=deshabilitado)
- **Expiración**: Días hasta que el reporte expire automáticamente (0=nunca, máx 3650)
- **Oculto**: Canal no visible públicamente (accesible solo por URL directa)

**Opciones Avanzadas:**
- **Navegación de cuestionario**: Muestra barra de progreso entre pasos
- **Selección de destinatarios**: Permite al denunciante elegir quién recibe su denuncia
  - *Seleccionar todos por defecto*: Todos los destinatarios preseleccionados
  - *Máximo seleccionable*: Límite de destinatarios (0=sin límite)
  - *Orden alfabético*: Ordenar lista de destinatarios
- **Cuestionario adicional**: Segundo formulario opcional
- **Sistema de puntuación**: Umbrales para prioridad (Medio/Alto) según respuestas

**UUID**: Identificador único para enlace directo al canal
