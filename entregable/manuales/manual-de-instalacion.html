Manual de instalación

Veridy y Kerna en tu computador, para Windows y Linux

Tiempo: 15 a 30 minutos la primera vez (casi todo es esperar). Las siguientes veces, 1 minuto.

Necesitas: un computador con Windows 10/11 o Linux, 8 GB de memoria, 6 GB libres en disco, conexión a internet y permiso para instalar programas.

Qué queda instalado: Veridy y Kerna funcionando en tu computador. Lo que hace la inteligencia artificial de Kerna ocurre en internet; tu computador solo la consulta.

1. Lo que vas a recibir

Una carpeta llamada veridy-kerna-local (o un archivo .zip con ese nombre: haz clic derecho → «Extraer todo»). Dentro hay:

ArchivoPara qué sirve
Instalar (Instalar.bat)Windows: instala y enciende todo con un doble clic.
instalar.shLo mismo, para Linux.
carpeta archivosLo que usan los instaladores, los manuales y Detener (apaga todo; lo que hiciste se conserva). No hace falta abrirla para instalar.
No cambies los nombres de los archivos ni los saques de la carpeta.

2. Instalación en Windows

Paso 1. Instalar Docker Desktop (solo la primera vez)

Docker Desktop es el programa gratuito que permite que Veridy y Kerna funcionen en tu computador sin instalar nada más.

1.1Abre el navegador y entra a docker.com/products/docker-desktop. Presiona «Download for Windows».
1.2Abre el archivo descargado (Docker Desktop Installer.exe). Si Windows pregunta si permites cambios, responde Sí.
1.3Deja marcadas las opciones que vienen marcadas (en especial «Use WSL 2») y presiona OK. Al terminar presiona «Close and restart»: el computador se reinicia.
1.4Después del reinicio, Docker Desktop se abre solo. Acepta las condiciones (Accept). Si pide iniciar sesión, puedes presionar «Skip» (Omitir). Si aparece un aviso para actualizar «WSL», sigue sus instrucciones y vuelve a abrir Docker Desktop.
1.5Espera hasta que en la esquina inferior izquierda de Docker Desktop diga «Engine running» en verde. Puedes minimizar la ventana.

Paso 2. Instalar Veridy y Kerna

2.1Abre la carpeta veridy-kerna-local y haz doble clic en «Instalar».
2.2Si aparece «Windows protegió su PC», presiona «Más información» y luego «Ejecutar de todas formas». Si el firewall pregunta por Docker, presiona Permitir.
2.3Se abre la ventana «Instalar Veridy y Kerna». Hace todo sola y va marcando cada paso con un ✓:
  1. Revisar que Docker Desktop esté instalado.
  2. Encender Docker Desktop (si estaba apagado, lo abre y espera).
  3. Copiar los programas (la primera vez tarda entre 2 y 6 minutos).
  4. Poner en marcha Veridy y Kerna.
  5. Esperar a que todo responda.
No la cierres mientras trabaja.
2.4Al terminar, la ventana dice «Listo. Veridy y Kerna están funcionando» y muestra tres botones: «Abrir la página de inicio», «Hacer una denuncia en Veridy» y «Panel de Kerna». Además, la página de inicio se abre sola en el navegador.

Si en algún paso aparece una ✗ roja, la ventana explica qué falta. Corrígelo y vuelve a hacer doble clic en «Instalar»: retoma desde donde quedó.

3. Instalación en Linux

Paso 1. Instalar Docker (solo la primera vez)

Abre una terminal (en Ubuntu: tecla Ctrl + Alt + T) y copia estas tres líneas, una por una, presionando Enter después de cada una. Pedirá tu contraseña.

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
sudo systemctl enable --now docker

Cierra la sesión del computador y vuelve a entrar (así tu usuario puede usar Docker). También sirve Docker Desktop para Linux, si lo prefieres.

Paso 2. Instalar Veridy y Kerna

2.1Abre la carpeta veridy-kerna-local, haz clic derecho en un espacio vacío y elige «Abrir en una terminal».
2.2Escribe ./instalar.sh y presiona Enter. Verás los mismos cinco pasos con un ✓ verde cada uno.
2.3Al terminar se abre la página de inicio en el navegador y la terminal muestra las direcciones de cada parte.

4. La página de inicio

Es el punto de partida de la prueba. Desde aquí llegas a todo con un botón y ves las cuentas de prueba. Si la cierras, vuelve a abrirla escribiendo localhost:8400 en el navegador.

  1. 1Aviso general: «Todo está listo» cuando ya se puede usar.
  2. 2Luces de estado: Veridy, panel de Kerna y conexión con Kerna en internet. Las tres deben estar en verde.
  3. 3Botón para hacer una denuncia.
  4. 4Cuenta del auditor (usuario y contraseña, con botón para copiar).
  5. 5Botón para entrar como auditor.
  6. 6Cuenta del panel de Kerna.
  7. 7Botón para entrar al panel de Kerna.
  8. 8Manuales.

Cómo usar cada parte está en el Manual de usuario.

6. Si algo no funciona

Lo que pasaQué hacer
«Falta Docker Desktop»Instálalo (sección 2, paso 1) y vuelve a abrir «Instalar».
«Docker Desktop no terminó de encender»Abre Docker Desktop desde el menú Inicio, espera «Engine running» y vuelve a abrir «Instalar».
Docker Desktop dice que falta «virtualización» o «WSL»Hay que activar la virtualización del computador (en la configuración de arranque, opción «Virtualization» o «VT-x»). Si es un computador institucional, pídelo al área de informática.
«Otro programa está usando los puertos 8400, 8401 o 8402»Cierra el otro programa (o reinicia el computador) y vuelve a abrir «Instalar».
La luz «Conexión con Kerna en internet» queda en rojoLa red no deja salir hacia Kerna. Ver el recuadro de abajo.
La página no abreEscribe localhost:8400 en el navegador. Si no responde, abre «Instalar» otra vez.
Redes de instituciones educativas o empresas. Kerna solo necesita poder navegar por HTTPS (el mismo tipo de conexión que usa cualquier página web segura, puerto 443). No necesita puertos especiales ni conexiones entrantes. Si la red bloquea sitios, el área de informática debe permitir estas direcciones:
  • *.chilecentral.azurecontainerapps.io (Kerna)
  • stkernadevg6mzy.table.core.windows.net (datos del panel)
  • api.loganalytics.io y management.azure.com (cifras del panel)
Si la red obliga a usar un «proxy», abre configuracion.env con el Bloc de notas, escribe la dirección del proxy en la última línea (por ejemplo HTTPS_PROXY=http://proxy.institucion.cl:8080), guarda y vuelve a abrir «Instalar». Como alternativa rápida, conecta el computador a otra red, por ejemplo el teléfono como punto de acceso.

7. Desinstalar

Primero usa Detener (carpeta archivos). Luego, en Docker Desktop, sección Containers, elimina el grupo veridy-kerna; en Images, elimina las que empiezan con veridy-local y kerna-; y en Volumes, los que empiezan con veridy-kerna (esto borra también las denuncias de prueba). Por último, borra la carpeta veridy-kerna-local y, si ya no lo necesitas, desinstala Docker Desktop desde «Agregar o quitar programas».
